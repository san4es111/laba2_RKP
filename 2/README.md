# Лабораторная работа № 2 Обработка числовых рядов

Это продолжение первой лабораторной, а не новый проект с нуля. В `calc/equation.py` вынесена расчётная часть старого `mathtool.py`: проверка коэффициентов и решение линейного или квадратного уравнения. Ввод коэффициентов с клавиатуры и решение по переданным коэффициентам сохранены. Разбор аргументов переписан на `argparse`, как требует новая работа. К этому приложению добавлены команды статистики, суммирования рядов и численного интегрирования.

## Структура проекта

- `mathtool.py` — точка входа и ввод-вывод команд;
- `cli.py` — разбор командной строки с помощью `argparse`;
- `calc/` — функции расчёта без ввода-вывода;
- `main.py`, `.gitignore` и `control_questions.md` — перенесены из первой лабораторной;
- `calc/equation.py` — модульная версия расчёта уравнения из старого `mathtool.py`;
- `numbers.txt` — пример данных для `stats`;
- `tests.txt` — команды, ожидаемый вывод, stderr и коды возврата;
- `control_questions.md` — вопросы и ответы к защите по первой лабораторной;
- `защита_лабораторной_2.md` — краткие ответы по темам второй лабораторной.

## Запуск

Запускайте команды из каталога проекта:

```powershell
python mathtool.py
python mathtool.py --help
python mathtool.py solve -a 1 -b -3 -c 2
python mathtool.py stats --input numbers.txt
python mathtool.py series --func sqplus --terms 6
python mathtool.py series --func sqplus --eps 0.0001
python mathtool.py integrate --func ratio --from 0 --to 20 --steps 1000
```

Для `stats` числа также можно передать через конвейер или ввести с клавиатуры. У `solve` коэффициенты можно не указывать: приложение запросит их.

## Проверка кода возврата

В PowerShell код последней команды доступен в `$LASTEXITCODE`. Ошибка в данных возвращает `1`, ошибка аргументов от `argparse` — `2`, успешное выполнение — `0`.
