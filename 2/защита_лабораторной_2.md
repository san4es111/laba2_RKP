# Подготовка к защите лабораторной работы № 2

## Функции, модули и пакеты

Расчётная функция возвращает результат и не печатает его: так её можно проверить отдельно, вызвать из другого обработчика и использовать с разным вводом-выводом. При импорте выполняются инструкции верхнего уровня, поэтому в модулях расчётов размещены объявления функций и констант. `if __name__ == "__main__"` оставляет запуск точки входа только при прямом запуске файла. Модуль — один файл Python; пакет — каталог с `__init__.py`.

Функция принимает данные параметрами, а локальные переменные существуют только во время её вызова. `solve` возвращает кортеж из вида уравнения, дискриминанта или `None`, и списка корней; присваивание `kind, d, roots = solve(...)` распаковывает его по переменным. Предел коэффициентов находится в `calc/equation.py`, потому что это ограничение расчёта уравнения.

`mean` — ссылка на функцию; `mean(values)` — вызов функции. В `stats.REPORT` названия, функции и форматы объединены в таблицу, поэтому для нового показателя нужны сама функция и строка таблицы. Цикл суммирования ряда принимает функцию слагаемого параметром, потому что алгоритм накопления одинаковый для разных формул.

## Аргументы и команды

Разбор по позициям ломается при нескольких командах: например, `solve -a 1 -b 2 -c 3` и `integrate --func ratio --from 0 --to 1 --steps 3` имеют разное число аргументов и разную структуру. `argparse` сначала выбирает подкоманду через `add_subparsers`, затем разбирает её параметры через `add_argument`.

На втором этапе проверяются допустимость имени, наличие значения и обязательность параметра. `argparse` также проверяет типы и обязательные параметры; повторный параметр он обычно принимает и оставляет последнее значение. Значение нужно проверить до использования, иначе обращение к отсутствующему параметру вызывает ошибку программы. Справка без команды печатается, когда `args.command is None`, с кодом 0.

Код 0 означает успех, код 1 — ошибка входных данных или файла, код 2 — ошибка синтаксиса командной строки от `argparse`. Новую команду добавляют при настройке её аргументов в `cli.py` и регистрируют отдельный обработчик в `HANDLERS`.

## Циклы

`while` сначала проверяет условие, `do/while` в других языках сначала выполняет тело. В Python цикла с постусловием нет; его записывают через `while True` и `break`/`return` внутри. `for` перебирает элементы последовательности, а `range` создаёт целочисленную последовательность; правая граница `range` не включается. `break` завершает ближайший цикл, `continue` переходит к его следующему повторению.

Циклу с заранее неизвестным числом повторений нужен предел, чтобы ошибка формулы или недостижимое условие не оставили программу в бесконечном цикле. Сумма и количество начинаются с 0, произведение — с 1, минимум и максимум — с первого элемента. Неверный старт смещает сумму/количество или может исказить сравнение минимума.

Фрагмент с `n = 71`, `b = 3` печатает `2212` — цифры числа 71 в троичной системе в обратном порядке. Алгоритм Евклида для 792 и 663 печатает `3`. Цикл перебора делителей числа 45 печатает `6`.

## Вещественные вычисления и алгоритмы

Числа с плавающей точкой хранятся в двоичном формате, и десятичные дроби вроде 0,1 обычно представляются приближённо, поэтому `0.1 + 0.2 == 0.3` ложно. В вычислениях сравнивают разность с допустимой погрешностью либо применяют `math.isclose` с выбранными допусками.

Координату интегрирования считают как `a + i * dx`, чтобы каждый шаг был привязан к исходной точке и целому номеру шага. Накопление `x += dx` добавляет округления; условие `while x < b` может сделать лишнее или недостающее повторение. Цикл `for i in range(steps)` гарантирует ровно заданное количество прямоугольников.

Дисперсия считается в два прохода: сначала среднее, затем квадраты отклонений. Формула «среднее квадратов минус квадрат среднего» вычитает близкие большие числа и может потерять значащие цифры.

Число знаков для ряда берётся из `DIGITS = ceil(-log10(MAX_EPS))`. При `MAX_EPS = 0.0001` это четыре знака. Условие остановки ограничивает погрешность величиной `eps`, но четыре округлённых знака гарантирует только погрешность меньше 0,00005. При `MAX_EPS = 0.000001` формат станет шестизначным, если `DIGITS` оставить вычисляемым.

Для `sqplus` модуль слагаемого равен `1/(n²+1)`: чтобы он стал меньше 0,0001, нужно `n = 100` (слагаемое включается в сумму). Для `third` модуль равен `1/(3n)`, поэтому нужно `n = 3334`. При 1000 шагах для `ratio` интеграл печатается как 16,9459, а точное значение около 16,9555: первые знаки приблизительны из-за метода левых прямоугольников. Четыре знака вывода задают формат, а фактическая точность зависит от функции, отрезка и числа шагов.

## Проверки приложения

Функции, которые возбуждают `ValueError`, сообщают о неверных коэффициентах, неподходящем количестве чисел, ошибках ввода, пределах точности ряда и параметрах интегрирования. Обработчики не печатают промежуточный результат до полной проверки параметров; исключения перехватываются в `main`, который пишет сообщение в stderr.

Пустая строка в файле пропускается как пустая строка данных. Если весь файл пуст или содержит только пробелы, приложение пишет `ОШИБКА: последовательность пуста` и возвращает 1. Формула ряда печатается только после проверки параметров и успешного расчёта, поэтому при ошибке stdout остаётся пустым.
